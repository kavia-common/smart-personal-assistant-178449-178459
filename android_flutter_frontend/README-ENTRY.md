# Android Module Entry (Gradle Declarative DSL)

This is the root of the Android project.

Build using the module’s Gradle wrapper:
- ./gradlew :app:assembleDebug

Key files:
- settings.gradle.dcl (Declarative DSL)
- app/build.gradle.dcl
- list/build.gradle.dcl
- utilities/build.gradle.dcl
- gradle/wrapper/gradle-wrapper.properties
